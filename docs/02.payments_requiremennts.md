# 결제 모듈 요구사항 분석 및 기능 목록

## 📌 기본 정보
### 프로젝트명: 
신발 브랜드 온라인 쇼핑몰 결제 모듈

### 사용하게 될 기술: 
React, JavaScript

### 문서 작성자: 
김미경

## 📝 고객 요구사항 정리
1. 여러 개의 카드를 등록할 수 있게 해주세요.
2. 카드 등록 과정에서 민감한 정보가 바로 노출되지 않도록 해주세요. (카드 뒷면 8자리, 보안 코드)
3. 상품 목록에서 담기 버튼 바로 옆에 ‘결제’ 버튼을 추가하여 동작할 수 있게 만들어주세요.
5. 중간 결과물 확인용 테스트 url 를 보내주세요.
6. 2주 후에 결과를 확인할 수 있게 해주세요.
   
## 📋 기능 목록
- 카드 번호 input
  - `<CardNumberInput />`
- 카드 만료일 input
  - `<ExpiryDateInput />`
- 카드 소유자명 input
  - `<CardOwnerInput />`
- CVC 번호 input
  - `<CardCVCInput />`
- 카드 비밀번호 input
  - `<CardPasswordInput />`
