# 상품 목록 페이지 리뷰

## 고객사 요구사항
1. 20~30대가 타깃인 신발 브랜드이므로 모바일 환경에서의 사용성을 중요하게 생각합니다. 
2. 상품 목록 페이지에서 상품 사진이 잘 보이게 카드 형태로 제작합니다.
3. 장바구니 페이지 상단 헤더에서 실시간으로 상품 개수를 표시합니다.
4. 작업 결과물 확인을 위해 테스트 url을 제공합니다.

## 요구사항에 따른 기능 동작 확인
1. "장바구니 추가" 버튼 클릭 시 장바구니에 담긴 상품 개수가 표시됩니다.
2. 모바일 환경에서 사용이 용이하도록 화면을 구성했습니다. 

### 1. 모바일 환경 구성
모바일 사파리, 삼성 브라우저에서 접속시 정상 동작함을 확인할 수 있습니다.

### 2. 신발 상품 사진
브랜드 별로 사진과 간단한 설명과 함께 카드 형식으로 제작했습니다. 

### 3. 장바구니 담기 기능
장바구니 담기 버튼을 누르면 선택한 상품이 장바구니에 추가됩니다.
