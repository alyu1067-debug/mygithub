# 상품 목록 페이지 프로젝트

## 프로젝트 개요

- 이 상품 목록 페이지는 고객이 상품을 보기 편하게 표시하고, 선택한 상품을 장바구니에 추가해 확인할 수 있는 기능을 제공합니다. 
- 작성자: 김미경


## 개발 환경

React 17.0, JavaScript ES6

## 설치 및 실행 방법

npm start


## 컴포넌트 구조

주요 컴포넌트들의 구조와 역할

예시:

- `ProductList`: 상품 목록을 카드 형태로 보여줍니다.
- `CartButton`: 상품을 장바구니에 추가합니다.
- `CartIcon` : 헤더에서 장바구니 상품 개수를 실시간으로 표시합니다.

## 테스트 방법

npm test

## 유의사항 및 알려진 이슈

- 현재 상품이 화면에 6개밖에 보이지 않는데 무한 스크롤을 추가하고 싶습니다.
- 가격이 표시되지 않는 이슈가 있습니다.
